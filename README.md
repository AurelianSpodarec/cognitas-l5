## Installation

Clone this repo to your local machine using: `git clone https://github.com/AurelianSpodarec/ogloszenia-anglia`

### Setup

Inside the website root folder, run the following commad:
```
npm install
```

To start development enviroment, run:
```
npm run
```

To have the assets for production, run:
```
npm build
```

Idealy you should only keep the WP files and the build folder on the server, without the assets folder.
